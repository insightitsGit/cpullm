# Security policy

Report suspected vulnerabilities privately through the repository's
[Security advisories](https://github.com/insightitsGit/cpullm/security/advisories/new).
Include the affected version, the smallest reproducible example, and the
observed impact. Remove credentials, private documents, and personal data
from the example.

Check the latest published version when reproducing an issue.
[PyPI releases](https://pypi.org/project/cpu-llm/#history)
