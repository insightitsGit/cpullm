# Contributing to CPU-LLM

Use GitHub issues for reproducible bugs and feature requests. Include the
package version or commit, Python version, operating system, and a small
example. For retrieval issues, include the prompt, synthetic source text,
expected outcome, and actual result.

See [development database setup](docs/development-database.md) for PostgreSQL
and pgvector. Run the relevant tests with `python -m pytest` and summarize
the checks in your pull request. Report vulnerabilities through the
[security policy](SECURITY.md).
