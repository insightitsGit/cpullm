RefundProof is a sales and use tax overpayment review for a finance team. It recomputes tax charged against correct tax on one invoice line and keeps expired, uncertain, duplicate, and unverified dollars out of the actionable total.

A RefundProof trigger is a review request that names the vendor, the invoice, the tax charged, and the correct tax. A question that only asks what RefundProof is stays on this stored sentence.

RefundProof evidence is a SHA-256 match between the finding and the registered source bytes and rule bytes. A hash without those bytes stays unverified, and the check does not approve the finding or file a return.

A recovery packet is a tracked vendor refund that already names a human reviewer and a review time. An expired deadline, a credit note, or a suspected duplicate stays readable and is left out of the actionable total.

LedgerCovenant is an evidence-backed covenant calculation for a lender. It resolves the governing provision, picks one reported figure by source authority, and compares the scaled ratio with the threshold.

A LedgerCovenant trigger is a decision request that names the threshold and the source of each figure. A question that only asks what LedgerCovenant is stays on this stored sentence.

A source lattice is a ranking of reported figures by who signed them. The compliance certificate outranks the audited financials, and two figures of equal rank are a conflict rather than an average.

An add-back cap is a limit that can refer to the amount it caps. The check iterates from the uncapped base until the amount settles, and a definition that does not settle is refused.

A covenant outcome is compliant, breach, waived, or not applicable. A waiver keeps a breach on the record, and the check does not declare a default.

Ledgerlock is a mortgage attestation gate before a loan-system update. It returns accept, review, or refuse for an extracted income or asset number.

A Ledgerlock trigger is an attestation request that names the document type, the field, the confidence, and the source span. A question that only asks what Ledgerlock is stays on this stored sentence.

An accepted field is an extracted number whose confidence clears the document floor and whose span contains that number. A missing span stays in review, and a mismatched span is refused.

A finance validation is a check over the fields written in the question. It is not a tax filing, a default declaration, or a write into a loan system.
