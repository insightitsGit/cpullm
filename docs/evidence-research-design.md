# Evidence and research workspace design

CPU-LLM already produces source spans, calculation receipts and research methods.
Expose these outputs directly in client views. Keep each item tied to its role:
a quote supports attribution, a calculation reports the operation, and a
hypothesis carries a test and uncertainty.

The evidence panel travels with the finalized answer. Clients can expand
individual source excerpts and the existing calculation trace. Source metadata
is copied where available. The panel must never broaden source access.

Research captures the model requested by the user and labels departures as
alternatives. Comparable bound conflicts keep the observable, units and
provenance from the existing abductive comparison. An empty intersection
applies only to the cited bounds and assumptions.

An execution card couples a candidate to its premises, test and missing inputs.
Applications explicitly select a candidate and supply a trusted numerical
adapter, grid and sourced limits. The scan executes the same model across all
constraints and returns a trace of sampled points. A result applies to the
supplied model and grid.

Plain-English research views are rendered from typed values. The technical
wording and exact passages stay available. The initial view covers the SIDM
boundary adapter. Unsupported views retain the technical wording.
