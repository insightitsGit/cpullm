# Public announcement wording

cpu-llm 1.11.1 is an **Evidence-Based AI Engine** for CPU-first document questions
and explicit rule checks. It combines retrieval, bounded sentence construction,
source evidence and recognized calculations. Document queries require
PostgreSQL/pgvector and pretrained encoder assets. Code is Apache-2.0; bundled
WikiText-2 data has separate CC BY-SA 3.0/GFDL terms.

The healthcare and finance examples demonstrate authored software fixtures,
including refusals and numeric policy boundaries. They are not clinical
validation, regulatory approval or an independent comparison with hosted models.

Use this description consistently. Avoid universal accuracy, zero-hallucination,
production HTTP readiness and first-of-its-kind claims. Ordinary optional learned
fallbacks have different verification limits. Only dense and identity projection
heads are trained and bundled. Related evidence-preserving approaches, including
VerbatimRAG, exist; no head-to-head superiority result is established here.

The HTTP patch fixes request-thread ownership; it does not establish concurrent
throughput. Container execution is still unverified on the maintainer's host.
