# Consuming cycle data in responses

Date: November 4, 2026. Source implementation after 1.11.2; no PyPI publication.

## Trigger contract

Whole explicit show/find/explore/explain/describe requests for loops/cycles
for/through/around/involving a named label activate standalone discovery. A
supported document request can end with “including relationship loops through
Alpha”. Bare article requests never silently enable expensive cycle traversal.
Quoted, negative or background statements are not trigger instructions. Multiple
document topics require an explicit loop seed. Python/HTTP cycle_search options
override the prompt seed, retaining validated resource limits.

## Data flow

Standalone: guard/scope -> fixed source snapshot -> six-channel cycle discovery
-> cycle_compose -> cycle_verify -> attributed path response.

Document: research plan -> one fixed authorized/as-of snapshot -> ordinary neutral
and optional tone composition -> cycle discovery from that same snapshot -> path
composition/verification -> relationship-loop section -> combined proof receipts.
This avoids a second retrieval and incompatible source versions. Additional loop
proofs join the parent answer_evidence after style verification. Canonical source
quotation text retains both original document records and cycle source wording.

Strict mode disables both prompt- and API-triggered loop exploration before
retrieval. Existing ordinary graph registration remains 27 nodes; these are
separate orchestration stages. Routing registry, JSON mapping and OpenAPI document
the implemented consumers and example request bodies.

## Sentence contract

Example:

```text
The source records describe a closed lexical path: Alpha causes Beta; Beta causes Gamma; Gamma causes Alpha.
```

The generator preserves whole source clauses in edge order. The independent
verifier parses them, re-extracts directed source claims, checks original chunk
hashes/spans, checks every edge connection and verifies simple path closure.
Source proofs for equivalent duplicate claims are retained and validated too.
It rejects changed values, reversed direction, omitted intermediate steps,
changed evidence or fabricated closure. Unsupported punctuation is left as literal
path quotations only after source/path validation; invalid proofs never fall back
to published text. It never infers “Alpha causes Gamma” from an intermediate path.

Each sentence exposes edge IDs, source IDs, all six channel assessments and its
verification/lexical qualification. Unknown/unavailable channels are not positive
votes. Source truth and homonym disambiguation remain unverified. A taxonomy cycle
can indicate a data-quality problem and must not become an inheritance proof.

## Budgets and coverage

All discovered cycles that fit are consumed, rather than returning only the first.
Presentation respects 100,000-character/500-proof standalone limits; document
integration uses the remaining 200,000-character and 500-source-record allowance.
Whole paths are included or omitted, not silently shortened. Omission counts and
truncation are explicit; the original bounded discovery metadata remains available.
No-cycle results and incomplete search do not discard independently useful facts.

Document coverage reports cycle counts found/presented, discovery completeness,
presentation truncation, separate cycle-body words and combined body words.
The main-document word target remains separate from the appended cycle analysis.
Paths are attached after tone composition, preserving their exact source clauses.
