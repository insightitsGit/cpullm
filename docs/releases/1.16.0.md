# cpu-llm 1.16.0: prepared for owner upload

This release adds Deepen's research review to the Frontier and Deepen nodes published in 1.15.0. Frontier's
candidates, ranking, scores and limits are unchanged.

## Changes since 1.15.0

- **Deepen research review** (commit `a09952e`):
  - semantic bridge warnings;
  - a composition assessment separate from per-link support;
  - operational plans with `readiness` and `research_actions`;
  - candidate-control roles, never adjusted automatically;
  - cited source context;
  - progressive "Go deeper" follow-ups;
  - an optional novelty review against the knowledge base, plus an off-by-default, operator-registered literature
    reviewer.

  See the [specification](../deepen-research-strengthening-spec.md) and [Deepen](../deepen-node.md).
- **The Deepen envelope:** `deepen={"hypothesis": ..., "definitions": ..., "protocol": ..., "novelty": True}`.
  Existing text and Frontier-hypothesis inputs still work.
- **Frontier/Deepen correctness fixes** (commit `a4cbb03`): end-to-end direction checks, negation keeping its
  relation, and checks sharing Frontier's request budget. These were already in the published 1.15.0 build.
- **README:** version, install-from-GitHub line, and the research-review section are marked 1.16.0.

## Verification

See the [build validation](1.16.0-build-validation.md) and the
[before/after comparison](../reviews/2026-11-22-deepen-review-check/report.md):
- Frontier output was identical on all 15 evaluation prompts;
- Deepen verdicts were identical on 7 hypotheses;
- the new review flags appear where expected.
