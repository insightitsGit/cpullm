# cpu-llm 1.11.1 HTTP ownership patch

Published on PyPI November 4, 2026 UTC (November 3 Pacific).
Code: Apache-2.0. Bundled WikiText-2 data: separate CC BY-SA 3.0/GFDL terms.

## Fixed behavior

The 1.11.0 stdlib HTTP server cached an appliance across request threads even
though its SQLite-backed graph/format state belongs to its creation thread.
Ordinary calls from another client could raise `sqlite3.ProgrammingError` and
close the connection without a JSON response. Strict requests could work while
the ordinary request failed, so header-only tests did not reveal the defect.

The server now executes requests serially on its serving thread. Lazy tenant
factories construct and reuse the appliance there. HTTP responses explicitly
close connections so an idle HTTP/1.1 keepalive cannot hold the serial server.
The CLI retains its existing authenticated routes, request fields and strict
policy precedence. This is not a new concurrency/throughput claim.

Applications embedding `LocalService` must keep appliance construction on the
serving thread, or supply a lazy factory that does so. A preconstructed appliance
from a different thread remains invalid. The shipped CLI uses a lazy factory.

## Setup and documentation

The repository now provides Compose/pgvector initialization, transferable encoder
cache instructions and an offline cache checker, plus a validated OpenAPI 3.1
document describing all four routes and ordinary/strict examples. The OpenAPI
file is documentation; no Swagger/OpenAPI route is added to the server.

The `v1.11.0` tag points to `75425fc`, whose 113 Python source files were checked
against the published wheel. It is not moved to this patch. Historical 1.11.0
artifacts and their hashes remain unchanged.

## Upgrade and publication

Install the published patch with `python -m pip install cpu-llm==1.11.1`.
The original manually uploaded artifacts remain unchanged. See
[publication hashes](1.11.1-publication.json).

Use exact filenames and the final validated hashes. No API tokens should be
placed in source or chat. See `1.11.1-build-validation.md` and the public-artifact
audit report for actual results and the separate Docker Desktop host blocker.
