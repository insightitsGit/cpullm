# cpu-llm 1.11.2: prepared for owner publication

This release is built and checked, not uploaded to PyPI by this task. It includes
the runtime hardening and enterprise-facing documentation following 1.11.1.

- Explicit opt-in for automatic learned writer fallback through
  `CPU_LLM_ALLOW_LEARNED_WRITER=1`; strict bypass remains unchanged.
- Warnings for explicit child-safety compatibility settings that the appliance
  does not apply; standalone gate remains unvalidated.
- Bounded HTTP body reads: 1 MiB cap, 10-second socket inactivity timeout,
  framing/encoding checks and body-timeout response. No total compute deadline.
- Exact bare-number equivalence and explicit mass/volume aliases for strict
  conflict comparison, preserving source text and proofs.
- Enterprise evidence positioning in README and PyPI description, with scoped
  healthcare/finance examples and commercial pilot enquiries.
- Prominent Apache-2.0 code versus WikiText-2 CC BY-SA 3.0/GFDL data disclosure;
  consolidated third-party notice included in wheel/source distribution.
